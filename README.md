Esse projeto correspondente ao trabalho final da disciplina 
"Computação Científica e Análise de Dados" onde são aplicados algoritmos usando algebra linear
nas ciências de dados.

Para o projeto foram utilizados os algoritmos:
PCA, que reduz a dimensão dos álbuns, que são representados por vetores, da dimensão 5 para a 2. 
K-means, para a clusterização, que após o PCA "escolhe" onde o album selecionado pelo usuário ficará.CA

Os três clusters escolhidos foram os albuns:
"Sour", da cantora Olivia Rodrigo. Um album mais melancólico, mais feminino.
"Rodeo", do rapper Travis Scott. Um álbum com uma letra mais pesada sobre vicios e excessos, que agrada o publico hetero.
"Renaissance", da diva pop Beyoncé. Um album com uma sonoridade mais dancante, com o ritmo House bem presente, o que agrada LGBTs.

O k-means realiza somente uma iteração para observar onde ficaria o álbum.

Projeto desenvolvido por Rafael Albuquerque, no mês de julho de 2026.
